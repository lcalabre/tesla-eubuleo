# Strumenti di bordo

Pagine statiche per il telefono, usate in auto.

- **[Tachimetro](https://lcalabre.github.io/tesla-eubuleo/tachimetro.html)** — quadrante 0-200 km/h
  che legge il GPS del telefono. Funziona su qualunque telefono e con qualunque auto: la velocità
  viene dal ricevitore GPS, non dal veicolo. Non raccoglie e non invia niente.

Il sito serve anche la chiave pubblica di un'applicazione Tesla Fleet API, in
`/.well-known/appspecific/`. È una chiave pubblica: serve a Tesla per verificare il dominio.
